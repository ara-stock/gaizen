## AIは「水や電気」になる

スマートフォンが登場したとき、それが全ての情報アクセスの入口になるとはすぐには信じられませんでした。AIも同じです。今から数年後、私たちはAIを通じて検索し、仕事をし、意思決定を行うようになる——その確信が、以下の4社への投資の起点にあります。

:::comment
サム・アルトマン氏が「AIは電気のようになる」と話していたとき、まさに同じことを考えていました。水道代や電気代を払うように、AIの利用料を毎月払う時代が来る。そしてそのインフラを持つ企業が、最も安定した長期収益を得る。この確信は今も変わっていません。AIが全てのインターフェースになる——これが私の投資論の根幹です。
:::

---

## Microsoft（MSFT）— 企業へのAI浸透を握る

### OpenAI株とクラウドの複合効果

MicrosoftはOpenAIへの大規模出資（総額130億ドル超）を通じて、ChatGPTの商業利用権を事実上確保しています。Azure OpenAI ServiceとしてクラウドAPIで提供しており、企業が生成AIを使うとき、その多くがAzureを経由します。

| 事業 | AIとの接点 |
|------|-----------|
| Azure | AI APIのインフラ・OpenAI連携 |
| Microsoft 365 | Copilot（月額$30追加課金） |
| GitHub | Copilot for Developers（コード補完） |
| LinkedIn | AI採用・人材マッチング |

:::comment
Microsoftを選んだ理由はシンプルです。**OpenAIの株を多く保有している**から、ChatGPTが成長するほどMicrosoftが潤う構造です。さらにGitHubを持っているため、開発者コミュニティとのつながりは強い。そしてOffice 365はすでに世界中の企業に根付いている。AIをそこに組み込む（Copilot）だけで、既存の顧客基盤から追加収益を得られる。企業へのAI導入がこれから加速する流れの中で、Microsoftは最も有利な位置にいると考えています。

一方で、**PowerPointやExcel、Docsのような既存のOfficeツールは、AIによって不要になっていく可能性を秘めています**。AIが資料を生成し、スプレッドシートを自動で作成し、文書を書いてしまうなら、ツールそのものの価値は薄れていく。これはMicrosoftにとっての構造的なリスクです。しかしだからこそ、Microsoftはカウンターとして自らAIを保有せざるを得ない。OpenAIへの出資はその防衛的な側面も持っています。既存の収益モデルが侵食されうる中で、その侵食者の株主であり続けるという選択です。
:::

### 財務面の強さ

- 売上高：2,817億ドル（FY2025実績、前年比15%増）
- Azure売上高：750億ドル超（前年比34%増）
- Microsoft 365 Copilotの企業導入が急拡大中
- 自社株買いと増配を継続（配当貴族の水準）

## Alphabet（GOOGL）— 自前AIと最強のインターフェースを両立する

### Geminiとマルチモーダル——自社でAIを作れる

AlphabetはMicrosoftと異なり、主力AIモデルを外部に依存していません。自社開発の**Gemini**はテキスト・画像・音声・動画を横断するマルチモーダルモデルであり、Google Cloud経由で企業向けAPIとして提供しつつ、AndroidやChromeへの深い統合によりエンドユーザーへのリーチも確保しています。

:::comment
AlphabetをMicrosoftと並べて保有している理由は、**自社でAIを開発している**という点にあります。MicrosoftはOpenAI依存ですが、AlphabetはGeminiを内製しています。AIがコモディティ化した場合、外部調達より内製の方が圧倒的に有利な立場になる。またGeminiのマルチモーダル性能は他モデルと比較しても際立っており、これは純粋な技術力の差です。
:::

### 自社TPU——NVIDIAに依存しない基盤

Alphabetは2015年からTPU（Tensor Processing Unit）を自社設計し、AI学習・推論の両方に活用しています。Geminiの開発・運用コストを他社より低く抑えられる構造は、長期的な競争優位として機能します。AIインフラのコストが競争の焦点になるほど、この堀の価値は大きくなります。

### YouTubeという「消えないインターフェース」

AIがどれほど進化しても、人が動画コンテンツを消費する欲求はなくなりません。月間ログインユーザー25億人超を抱えるYouTubeは、Alphabetが持つ最強のフロントエンドです。

:::comment
AIが全てのインターフェースになるとしても、そこに至るまでの間、YouTubeは人々の時間を最も多く占有するメディアであり続けます。そしてインターフェースを持っている限り、広告需要は絶えない。Alphabetはフロントエンド（Search・YouTube）とバックエンド（Google Cloud・TPU）を同時に自前で持つ、DFAの中でも特異な構造を持つ会社です。
:::

| 資産 | 強み |
|------|------|
| Gemini | 自社開発マルチモーダルAI |
| Google Cloud | TPU・Gemini API基盤 |
| Google Search | 世界の検索シェア90%超 |
| Android | スマートフォンOSシェア72%超 |
| YouTube | 月間25億人・動画のデファクト |
| 広告事業 | デジタル広告の寡占 |

## Apple（AAPL）— 物理デバイスは絶対に必要

AIがどれほど進化しても、ユーザーはデバイスを通じてアクセスします。iPhone・Mac・AirPods・Apple Watchは、最もプレミアムな「AIのフロントエンド」として機能し続けます。

:::comment
AIが全てのインターフェースになるとしても、そのAIを使うための物理デバイスは必ず必要です。AppleはiPhone・Mac・AirPodsで最もリッチな出口を持ち、Apple Intelligenceでそれを自社エコシステムに囲い込んでいます。AndroidやWindowsとは異なる強固なロイヤリティが、Appleの最大の堀です。
:::

### Apple Intelligenceとプライバシー戦略

2024年に発表されたApple Intelligenceは、オンデバイス処理とPrivate Cloud Computeの組み合わせで動作します。ユーザーデータを外部サーバーに送らない設計は、欧州・日本などプライバシー規制が厳しい市場での差異化要因です。

### MicrosoftのカウンターとしてのApple

:::comment
**AppleはMicrosoftへのカウンターでもある**と考えています。PowerPointやExcelがAIで不要になれば、Windowsに縛られる理由も薄れます。Officeからの解放はMacへの移行を後押しする可能性があります。AI開発の現場ではすでにMacが優位とされており、エンジニアやクリエイターのMacシェアは顕著。iPhone・AirPods・MacをAppleで統一するライフスタイルには、論理を超えたブランド引力があります。
:::

## Amazon（AMZN）— Anthropicを持つクラウドの覇者

### AWSとAnthropicの連合

AmazonはAnthropicへの大規模出資（総額40億ドル）を通じて、Claude APIをAWS（Amazon Bedrock）経由で優先展開しています。Microsoft-OpenAI連合に対するAmazon-Anthropic連合の構図です。

:::comment
AmazonがAnthropicの株を持っているというのは、私にとって重要なファクターです（余談ですが、このサイトで使っているAI自体もAnthropicのClaudeです）。AWSはすでにクラウドのシェアトップ水準にあります。そこにAnthropicのAI技術が乗ることで、企業向けAIサービスの提供体制が整う。加えてECという巨大なインターフェースも持っている。Amazonは複数のインターフェースとインフラを同時に握っている、という意味で非常に重要な銘柄だと考えています。
:::

### Amazonの収益構造

| セグメント | 概要 |
|-----------|------|
| AWS | クラウドインフラ（営業利益の大半を占める） |
| 広告事業 | ECプラットフォーム上の広告 |
| Eコマース | 物流・サブスクリプション（Prime） |
| Amazon Bedrock | AnthropicのAI APIを含む生成AIプラットフォーム |

AWSの営業利益率は約35%（FY2025実績）を維持しており、ECの薄利を補って余りある収益エンジンになっています。売上全体の18%を占めるに過ぎないAWSが、営業利益全体の約60%を稼ぐ構造です。

## 「デバイス×クラウド×AI」という視点で整理する

:::comment
これら4社に共通するのは、**ユーザーとのタッチポイントを複数持っている**ことです。MSはOffice・GitHub・Azure。AlphabetはSearch・YouTube・Android。AppleはiPhone・Mac・AirPods。AmazonはEC・AWS・Prime Video。どの会社も単一事業ではなく、複数のインターフェースを持っている。だからAIが普及したとき、その恩恵を受けやすい構造になっています。
:::

| 企業 | デバイス/フロントエンド | AIモデル | クラウドインフラ |
|------|----------------------|---------|--------------|
| Microsoft | Windows・Surface | GPT（OpenAI） | Azure |
| Alphabet | Android・Pixel | Gemini | Google Cloud |
| Apple | iPhone・Mac | Apple Intelligence | iCloud |
| Amazon | Alexa・Fire TV | Claude（Anthropic） | AWS |

4社でデバイス・モデル・インフラを分散保有することは、「AIが普及する世界」に対する最もバランスの取れたエクスポージャーだと考えています。

## まとめ

「AIはインフラになる」というテーゼを起点に、Microsoft・Alphabet・Apple・Amazonへの長期投資を継続しています。それぞれが異なるインターフェースとインフラを持ちながら、AIの普及という同じ波に乗っています。
