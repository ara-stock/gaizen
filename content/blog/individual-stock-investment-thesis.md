## 結論：投資仮説は「当たる予想」ではなく「見直せる判断記録」

個別株を買う前に必要なのは、将来の株価を正確に予想することではありません。なぜ買うのか、何を確認し続けるのか、どの条件で考え直すのかを、自分の言葉で説明できる状態にすることです。

これを本記事では「投資仮説」と呼びます。私が実際に銘柄を調べる順番は次の通りです。

**時価総額 → 事業 → 決算 → サービス → 株価・PER・ROEなどの指標**

価格を最後に見るのが特徴です。値上がりしているから良い会社に見える、下落しているから割安に見える、といった株価起点の判断を減らし、先に「長く保有したい事業か」を考えます。

| 段階 | 確認すること | 最終的に残す一文 |
|---|---|---|
| 時価総額 | 企業規模と投資対象にする範囲 | なぜこの規模を選ぶのか |
| 事業 | 顧客、収益源、需要の持続性 | この会社は何で稼ぐのか |
| 決算 | 売上、利益、キャッシュフロー、固有指標 | 仮説は数字に表れているか |
| サービス | 使いやすさ、価格、競合との差 | 顧客が選び続ける理由は何か |
| 株価指標 | PER、ROE、同業・過去との比較 | 成長期待に対して高すぎないか |

---

## 1. 時価総額から見る

私は最初に時価総額を確認します。小型株の大きな上昇を狙うより、すでに需要、顧客、ブランド、設備を築いている大型企業を長く保有する方が自分に合っているからです。また、時価総額の大きい企業ほど、投資額も多くする傾向があります。

ただし、時価総額は「株価 × 発行済株式数」で決まる市場評価であり、安全性や事業品質を直接示す数字ではありません。大型企業でも業績悪化や規制、技術転換によって大きく下落します。最初の絞り込みには使えても、購入理由にはなりません。

確認するのは次の3点です。

- 自分が理解できる企業規模・事業領域か
- 売買したいときに十分な流動性があるか
- すでに保有する投資信託や個別株と、実質的に重複していないか

:::comment
私は、時価総額の大きい企業ほど投資額も大きくするよう意識しています。規模を築けた企業には、それだけの需要やブランド、事業基盤があると考えているためです。

一方で、時価総額が大きいだけで買うことはありません。最初に対象を絞り、その後に事業と決算を確認するための入口として使っています。
:::

---

## 2. 事業を一文で説明する

次に、その会社が誰から、何の対価として売上を得ているかを調べます。事業名を並べるだけでなく、利益が生まれる流れを一文にします。

たとえばAlphabetなら、「SearchとYouTubeでユーザーと広告主を集め、その資金をCloud・AIへ再投資する企業」です。MUFGなら、「国内の貸出を土台に、海外事業と手数料収益で利益源を分散する金融グループ」と整理できます。

ここで確認するのは、現在の売上規模だけではありません。

- 顧客がその商品やサービスを使い続ける理由
- 値上げや原価上昇に耐えられる収益構造
- 競合が短期間で再現しにくい設備、技術、ブランド、顧客基盤
- 5年後も需要が続くと考える根拠

一文で説明できない企業は、決算が良くても保有中の変化を判断しにくくなります。

---

## 3. 決算で「物語」を数字に変える

事業を理解したら、決算で実際の売上と利益を確認します。米国上場企業の場合、SECのForm 10-Kと10-Qには事業、リスク、財務諸表、経営陣による業績説明が掲載されています。日本株では、決算短信だけでなく決算説明資料、有価証券報告書も確認します。

最低限見る項目は次の通りです。

1. 売上高と営業利益が前年同期からどう変化したか
2. 営業利益率が改善しているか、悪化しているなら理由は何か
3. 営業キャッシュフローと設備投資の関係
4. 会社が示した次期見通しと、その前提
5. 投資仮説に固有の指標

固有指標は企業によって違います。AlphabetならYouTube広告、Google Cloudの売上・営業利益、設備投資です。MUFGなら貸出利ざや、資金利益、信用コスト、CET1比率を見ます。すべての銘柄へ同じ指標を当てはめるより、「購入理由がどの数字に現れるか」を先に決めます。

---

## 4. サービスを使い、数字に出る前の変化を探す

利用できる商品やサービスなら、自分で試します。使いやすさ、品質、価格、以前からの変化、競合へ乗り換えたいと感じるかを確認します。

ただし、自分の体験は一人分の観測です。Geminiの精度が上がったと感じても、それだけでAlphabetの利益が増えるとは限りません。反対に、法人向けクラウドや銀行の大企業向け融資など、個人では十分に試せない事業もあります。その場合は公式の顧客事例、契約状況、セグメント実績で補います。

サービスの使用感は仮説を作る入口、決算はその仮説を検証する材料と分けて考えます。

---

## 5. 最後に株価、PER、ROEを見る

事業と決算を確認してから、株価と指標を見ます。JPXは、PERを株価と1株当たり利益の関係、PBRを株価と1株当たり純資産の関係、ROEを自己資本からどれだけ利益を生んだかを見る指標として整理しています。

いずれも単独では購入判断になりません。

- PERが低い：成長鈍化や減益を織り込んでいる可能性がある
- PERが高い：高い成長が続く前提まで株価に含まれている可能性がある
- ROEが高い：収益性が高い一方、借入や一時利益の影響も確認する
- PBRが低い：割安とは限らず、資本効率や資産価値への懸念も考える

比較対象は、全市場の一律な基準ではなく、同業他社、その企業の過去、今後の利益成長です。AlphabetとMUFGを同じPERだけで比較しても、事業構造が違うため判断できません。

## 30〜70万円という購入基準と、足りていない基準

私は、最初の購入金額が30万〜70万円程度に収まる銘柄へ投資することが多いです。日本の内国株は取引所では原則100株単位で売買されるため、株価3,000円なら1単元は約30万円、7,000円なら約70万円になります。

これは「買えるかどうか」の基準であり、「どれだけリスクを取るか」の基準ではありません。同じ50万円でも、総資産500万円と5,000万円では影響が異なります。

現在、私はポートフォリオに占める銘柄ごとの上限を固定していません。ここは今の運用方法で不足している点です。売却上限を決めなくても、少なくとも次は購入前に確認する必要があります。

- 購入後、その銘柄が金融資産の何%になるか
- 同じ業種やテーマを合計すると何%になるか
- 投資信託の上位構成銘柄と重複していないか
- 半値になっても、生活や積立計画に影響しない金額か

時価総額が大きくても、集中による損失は小さくなりません。FINRAも、単一銘柄・業種・相関の高い資産への偏りが損失を増幅させる集中リスクを説明しています。私は一律の上限を設けていませんが、構成比を見ないこととは分けるべきだと考えています。

## 「下がったら買う」で待ち続けない

調べた企業をすぐ買えない主な理由は、現金余力がないときです。その場合はウォッチリストへ追加し、資金ができたときに改めて確認します。

一方、「もう少し下がったら買う」と待つと、買いたい人が多い銘柄や上昇中の銘柄はなかなか希望価格まで下がりません。長期保有を前提とし、現在の評価でも事業成長に見合うと判断した場合は、最安値を待たずに購入します。

:::comment
経験上、「下がったら買おう」と思う銘柄ほど下がらず、そのまま上がることが多くありました。長期で持ちたい企業なら、数%の安値を待ち続けるより、現在の株価で納得できるかを考えます。

私が比べているのは、現金で持ち続けるか、事業を持つ株式へ変えるかです。円高や利上げの可能性が高いと考える局面では現金を残し、金利が横ばいか低下方向なら資産へ振り向ける判断をすることがあります。
:::

ただし、利上げが必ず円高や株安につながるわけではありません。現金の額面が増えるわけでもありません。ここでいう「現金の価値」は、金利収入、為替、物価、株式の期待リターンと比べた相対的な魅力です。マクロ予想だけで全額を現金または株式へ動かさず、生活防衛資金と近い将来に使うお金は投資判断から分けます。

## Xは「気づく場所」、公式資料は「判断する場所」

日本株は原則として毎決算を確認します。米国株は決算、大きな値動き、サービスの変化があったときに詳しく見ます。ただし、すべての決算発表をリアルタイムで追えているわけではありません。Xで決算や株価反応を知ることも多くあります。

SNSは変化に気づくには便利ですが、投稿者が選んだ数字や解釈だけが流れてきます。次の順番を崩さないようにします。

1. Xやニュースで決算・値動きに気づく
2. 会社IR、決算短信、10-Qなどの一次資料を開く
3. 売上・利益だけでなく、見通しと一時要因を確認する
4. 株価反応とのずれが本当にあるかを考える

好決算なのに株価が下がった場合も、直ちに買い場とは限りません。市場予想に届かなかった、次期見通しが弱い、利益が一時要因だった、もともとの評価が高すぎた可能性があります。それらを確認した後も、事業価値と株価の反応に説明できない差が残るなら、初めて自分の「EDGE」の候補になります。

:::comment
大型企業は決算に関する投稿が多いため、Xを見てプラスかマイナスかを知ることがあります。決算が良いのに株価が下がっているときは、市場が見落としているものがないか確認します。

ただし、投稿だけで売買は決めません。何が良かったのか、なぜ下がったのかを一次資料で確かめ、それでも評価がずれていると思えたときに検討します。
:::

## 利益確定ではなく、事業が崩れたかで売る

私は株価が大きく上がっただけでは、基本的に利益を確定しません。事業の成長性と持続性が変わらない限り、保有を続けます。長く成長する企業を途中で売ると、その後の複利を失う可能性があるためです。

私の基本方針は、事業が大きく崩れるまで保有することです。これを点検項目にするなら、例えば次のように整理できます。以下は過去の売却記録ではなく、読者も使える確認項目の提案です。

- 購入時に期待した収益源が複数四半期にわたり悪化した
- 顧客がサービスを選ぶ理由や競争優位が失われた
- 経営陣の資本配分が変わり、利益が株主価値につながらない
- より魅力的な投資先があり、追加資金だけでは調整できない
- 銘柄または同一テーマの比率が、自分の許容できる損失を超えた

「含み益が大きいから売らない」と「事業が強いから保有する」は異なります。定期的に購入理由を現在形で説明できるか確認します。

## 実例：同じ判断シートでも見る数字は変わる

| 項目 | Alphabet | MUFG |
|---|---|---|
| 最初の購入理由 | YouTubeというユーザー接点 | 円安、金利、新NISAによる事業機会 |
| 現在の中心仮説 | Cloud・AIと自社インフラ | 国内利ざや、海外、手数料収益 |
| 決算で見る数字 | YouTube広告、Cloud利益、設備投資 | 資金利益、利ざや、信用コスト、CET1 |
| 買い増しの入口 | 5%以上の下落後に再点検 | 事業・金利・予想配当を再点検 |
| 見直す条件 | 広告とCloudの利益成長が崩れる | 利ざや・信用コスト・資本が複合悪化 |

詳しい判断記録は、[Alphabetを長期保有する理由](/blog/alphabet-investment-thesis/)と[MUFGを長期保有する理由](/blog/mufg-investment-thesis/)で公開しています。

## そのまま使える投資判断シート

私はこれまで購入理由をメモしていませんでした。そのため、以下は過去に使っていた記録用紙ではありません。この記事で紹介した調査手順を、読者が見直せる形にまとめるためのテンプレートです。

| 記録項目 | 記入内容 |
|---|---|
| 企業名・確認日 | 情報の基準日も書く |
| 時価総額 | 規模を選ぶ理由 |
| 事業を一文で | 誰から何の対価を得る会社か |
| 5年後も需要が続く理由 | 顧客、競争優位、代替リスク |
| 最新決算 | 売上、営業利益、キャッシュフロー、固有指標 |
| サービス確認 | 実際に使った感想、使えない場合の代替資料 |
| 株価指標 | PER、ROE、同業・過去との比較 |
| 今買う理由 | 待たずに資金を配分する理由 |
| 購入金額・購入後比率 | 30〜70万円だけでなく構成比も記録 |
| 買い増し条件 | 株価ではなく、事業条件とセットで書く |
| 仮説が崩れる条件 | 売却・再調査につながる具体的な変化 |
| 一次資料 | IR、決算、有価証券報告書、10-QのURL |

すべてを完璧に埋める必要はありません。ただし、「事業を一文で」「今買う理由」「仮説が崩れる条件」の3つを書けない状態では、購入後の判断も株価に引っ張られやすくなります。

## まとめ

私の個別株調査は、時価総額から始まり、事業、決算、サービスを確認し、最後に株価と指標を見ます。長期保有を前提にするからこそ、数%の安値を待つことより、5年後も需要が続く事業かを重視します。

一方、銘柄ごとの上限を決めていないことや、購入理由を記録してこなかったことは、現在の方法の限界です。購入後の構成比と、仮説が崩れる条件を1枚に残すことは、その限界を補う方法の一つです。

投資仮説は、買う自信を強めるためだけの文章ではありません。自分が間違っていたときに、何を見て判断し直すかを決めるための記録です。

本記事は特定銘柄の購入を推奨するものではありません。個別株には元本割れの可能性があり、投資判断はご自身の状況とリスク許容度に基づいて行ってください。
