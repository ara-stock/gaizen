## なぜ指標を使うのか

個別株を評価するとき、「この株は高いか、安いか」「この会社は稼げているか」を判断する物差しが必要です。

ROE・PER・PBRは、その中でも最も基本的かつよく使われる指標です。これらを理解せずに個別株を選ぶのは、価格を確認せずに買い物をするようなものです。

## ROE（自己資本利益率）：稼ぐ力の指標

### 計算式

```
ROE = 当期純利益 ÷ 自己資本 × 100（%）
```

### 意味

株主が会社に投資したお金（自己資本）を使って、どれだけ効率よく利益を生み出したかを示す指標です。

ROEが15%なら、100円の自己資本から15円の利益を生み出しているイメージです。

### 判断の目安

| ROE水準 | 評価 |
|---|---|
| 5%未満 | 低い（資本効率が悪い） |
| 5〜10% | 標準的 |
| 10〜20% | 優れている |
| 20%超 | 非常に高い（持続可能かを確認する） |

**日本株はROEが低い傾向があります。** 東証プライム市場の平均ROEは8〜10%程度で、米国S&P500構成企業の平均（15〜20%程度）と比べて低い。これが日本株が長期で出遅れてきた構造的な要因のひとつです。

東京証券取引所が2023年以降「ROE・PBRの改善」を上場企業に要請しており、近年は日本企業でもROE意識が高まっています。

### ROEの注意点

ROEが高くても、借入金（レバレッジ）を増やすことで数字が上がることがあります。財務健全性も合わせて確認が必要です。

## PER（株価収益率）：割安か割高かの指標

### 計算式

```
PER = 株価 ÷ 1株当たり純利益（EPS）
```

### 意味

「今の株価は1年分の利益の何倍か」を示します。PER20倍なら、現在の利益水準が続いた場合に20年分の利益を払って株を買っているイメージです。

### 判断の目安

| PER水準 | 評価目安 |
|---|---|
| 10倍以下 | 割安感あり（業績悪化懸念も要確認） |
| 15〜20倍 | 標準的（業種・成長率による） |
| 25〜30倍超 | 割高感あり（高成長期待が織り込まれている） |
| 50倍超 | 成長株・テーマ株に多い |

**PERは業種によって大きく異なります。** 成長性の高いテクノロジー企業は高PERが許容されますが、銀行・公益・素材などの成熟業種では低PERが普通です。同業他社との比較が重要です。

また、**過去の利益をもとにしたPER（実績PER）より、今期・来期予想をもとにした予想PERの方が実用的**です。

## PBR（株価純資産倍率）：帳簿価値との比較

### 計算式

```
PBR = 株価 ÷ 1株当たり純資産（BPS）
```

### 意味

「今の株価は、会社が持つ純資産の何倍か」を示します。PBR1倍なら株価と帳簿上の資産が等価。PBR1倍未満は「帳簿価値より安く買えている状態」です。

### 判断の目安

| PBR水準 | 意味 |
|---|---|
| 1倍未満 | 帳簿価値割れ（バリュー株の可能性） |
| 1〜2倍 | 標準的 |
| 3倍超 | ブランド・無形資産・成長性が評価されている |

**PBR1倍未満は必ずしも割安ではありません。** 業績が悪化している・将来的に資産が毀損する見込みがある場合、帳簿価値割れは合理的な評価かもしれません。

東証の要請により「PBR1倍割れ」の改善が日本企業に求められており、自社株買い・増配・資産売却を通じてPBRを引き上げようとする動きが活発化しています。

## 3つの指標の組み合わせ方

3指標をどう組み合わせるか、典型的な読み方を整理します。

**成長株を探す場合**
- ROE高（15%超）→ 稼ぐ力がある
- PER高（30倍以上）→ 市場が成長を期待している
- PBR高（3倍以上）→ 無形価値・ブランドが評価されている

**バリュー株を探す場合**
- PBR低（1倍前後）→ 帳簿価値と近い
- PER低（15倍以下）→ 利益に対して株価が抑制されている
- ROEが改善傾向 → 今後の回復余地がある

## 指標の限界：数字だけで判断しない

ROE・PER・PBRはあくまで「切り口」です。

- **業種が違えば比較できない**。PER15倍の銀行株とPER15倍のITサービス株は別物
- **過去の数字**。将来の成長・業界変化・経営判断は指標に反映されていない
- **一時的な要因で歪む**。特別利益・特別損失があると当期純利益が大きくブレ、PER・ROEが実態を反映しない

指標はあくまでスクリーニング（絞り込み）の道具です。「この指標が良いから買う」ではなく、「この指標が良い銘柄の中で、ビジネス・競合・経営者をさらに調べる」というプロセスが本質です。

## まとめ

- **ROE**：自己資本に対する収益性。10%超が優秀、日本株平均は8〜10%
- **PER**：利益に対する株価の割高・割安感。業種比較が重要
- **PBR**：純資産に対する株価の水準。1倍割れが必ずしも割安ではない
- 3指標を組み合わせて「成長株」「バリュー株」を区別する
- 指標はスクリーニングの道具。ビジネス・業界・経営の理解とセットで使う
