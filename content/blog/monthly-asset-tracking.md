## 月末に、口座を一巡して残高を記録する

私が記録しているのは、毎月の資産額です。Googleスプレッドシートの行に銀行や証券会社、列に月を並べ、最後に合計と先月比を出しています。手元の現金も含めますが、資産別の比率までは記録していません。

記録するのは、給料が入り、クレジットカードの支払いが終わった月末です。単月の上下より、年単位でどう変わったかを見ています。

:::comment
運用成績は、あまり確認できていません。給与や賞与から追加で投資しているので、増えた金額がそのまま運用益になるわけではないからです。

まずは毎月、銀行と証券口座を確認する。日が多少ずれても、記録が続くことを大事にしています。
:::

この管理方法をもとに、読者が使えるExcelを用意しました。ここからは筆者の実残高ではなく、**架空の金額を使った記入例**で説明します。

## Excelをダウンロードする

[月次資産記録テンプレートをダウンロード（.xlsx）](/downloads/gaizen-asset-tracking-template.xlsx)

会員登録は不要です。個人のGoogleアカウント、メールアドレス、筆者の実際の資産額を含まないファイルを配布しています。

| シート | 使い方 |
|---|---|
| 資産記録 | 銀行・証券会社・年金・ポイント・商品券・現金・暗号資産の残高を黄色いセルへ入力 |
| ダッシュボード | 最新入力月、合計、前月比、1月末比、総額とカテゴリ別の棒グラフを見る |
| 使い方 | 入力方法と集計の注意点を確認 |
| 記入例（架空） | 3か月の残高と計算例を見る。自分の資産記録には加算されない |

この表で集計するのは、入力した金融資産等の残高です。**住宅ローンなどの負債を差し引いた純資産ではなく、運用利回りや税務上の損益も計算しません。** ポイントや商品券は現金と同じ自由度では使えないため、生活費を確保する際は銀行・現金の小計を別に確認してください。

## 最初の入力は、この順番で進める

1. 「資産記録」シートで、使っている口座を確認する。口座名は変更できますが、小計・合計行は残します。
2. 記録する月の列へ、同じ時点の残高を円単位で入力する。表は2026年の1〜12月です。別の年に使う場合は月の見出しを変更します。
3. 証券口座は、株式・投資信託の評価額と口座内の預り金を含める。口座画面の総額に預り金が含まれている場合、足し直さないようにします。
4. iDeCo等を専用行に入力したら、証券会社の行に重ねて計上していないか確認する。
5. 合計を確認してから「ダッシュボード」を開く。前月比がおかしい場合は、売買判断より先に入力漏れを調べます。

手元の紙幣・硬貨は「現金」の行に入れます。銀行預金や証券口座の預り金までここへ再入力すると二重計上になります。暗号資産や外貨は記録日時点の円換算評価額を使い、毎月できるだけ同じ評価方法にそろえます。

## 記入例：190万円から197万円に増えた月

以下は説明用に4口座へ簡略化した架空の例です。金額の単位は円です。

| 口座 | 1月末 | 2月末 | 3月末 |
|---|---:|---:|---:|
| 楽天銀行 | 300,000 | 250,000 | 280,000 |
| 三井住友銀行 | 100,000 | 120,000 | 110,000 |
| 楽天証券 | 1,000,000 | 1,080,000 | 1,050,000 |
| SBI証券 | 500,000 | 520,000 | 540,000 |
| 合計 | 1,900,000 | 1,970,000 | 1,980,000 |
| 前月比 | 比較なし | +70,000 | +10,000 |

2月末の総額は197万円、1月末からの増加は7万円です。ここまでは残高だけで分かります。ただし、**7万円を運用益とは呼べません。**

仮に2月の給与等の収入が30万円、生活費等の支出が24万円だったとします。差し引き6万円が家計から残っているため、計算は次のようになります。

```text
資産額の増加                       70,000円
給与等の収入 − 生活費等の支出      60,000円
差額                               10,000円
```

すべての口座を同じ条件で記録し、資産の追加・除外や入出金の漏れがなければ、この差額は運用損益等を調べる手がかりになります。配当、税金、手数料、為替変動も含み得るため、売買で確定した利益とは限りません。

正確な運用利回りには、投資対象をどこまで含めるかと、入出金の日付・金額をそろえた計算が別途必要です。このExcelはそこまで行いません。

### 銀行から証券へ10万円移しても、資産は増えない

手数料や価格変動がないと仮定すると、銀行30万円・証券100万円の合計は130万円です。銀行から証券へ10万円移すと、銀行20万円・証券110万円になり、合計は130万円のままです。

銀行と証券を両方集計するこの表では、振替は**内部の移動**です。「証券口座への入金10万円」を別途総額へ加算すると、資産が水増しされます。逆に、証券口座だけの運用成績を計算する場合には、その10万円は外部からの入金として扱います。どこまでを集計対象にするかで区別してください。

## 空欄、ゼロ、記録漏れを区別する

| 状況 | 入力方法・表示 |
|---|---|
| まだ記録していない月 | その月を空欄にする。合計や前月比は空欄 |
| 確認した口座残高がゼロ | 数値の0を入力する。未入力とは区別される |
| 先月を記録し忘れた | 今月の合計は出せるが、前月比は比較不可 |
| 一部の口座だけ入力済み | 入力済み分だけ合計される。全口座がそろったかを自分で確認 |
| 1月末の記録がない | 1月末比は比較不可。2月以降から始めても記録自体は可能 |

銀行の振替処理中など、一時的に両方の画面へ反映されていない場合もあります。記録日を多少ずらしても、資金の移動が完了した状態で合わせる方が、理由の分からない増減を減らせます。

この表の「1月末比」は、1月末からの残高変化です。前年12月末を起点にした年間の増減とは異なります。暦年で振り返りたい場合は、前年末の記録も残してください。

## Googleスプレッドシートでも使えるか

ExcelファイルをGoogleドライブにアップロードし、Googleスプレッドシートで開く方法があります。[Google公式のExcelとSheetsの利用案内](https://support.google.com/docs/answer/9331167)で手順を確認できます。

取り込み後は「記入例（架空）」の合計が190万円・197万円・198万円になり、グラフが表示されることを確認してください。アプリによってグラフの見た目や数式の扱いが変わる場合があります。Googleアカウント上での動作は利用環境ごとに確認が必要です。

自分の残高を記入した後のファイルは、共有範囲を確認して管理してください。配布ファイルが匿名でも、書き込んだ残高や口座名まで匿名になるわけではありません。

## マイナスの月に、何を確認するか

私は給与が入ったら投資へ回しているため、先月比がマイナスだったという理由では積立を止めません。相場が下がっていれば、むしろ追加で投資したいと考える方です。

ただし、次の順番で残高を読むと、相場の問題と家計の問題を分けやすくなります。

1. 口座の入力漏れや二重計上がないか。
2. 大きな買い物・税金・賞与など、普段と違う入出金があったか。
3. 次の生活費・カード支払い・予定支出を現金で賄えるか。
4. そのうえで、投資商品の値動きによる変化を確認する。

年単位でも資産が減ることはあります。「長く続ければ必ず増える」と判断せず、記録をもとに次の入金と現金の備えを考えます。生活資金の決め方は[50万円から始めた生活防衛資金](/blog/emergency-fund/)、配分の見直しは[リバランスの考え方](/blog/portfolio-rebalancing/)にまとめています。
